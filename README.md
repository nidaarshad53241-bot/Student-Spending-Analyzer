# Student Spending & Budget Analyzer

Week 4 project of **IEEE LGU Student Branch - AI/ML Cohort One**.

## Project Description
This project is a Google Colab notebook that analyzes a small, *fictional* student-spending dataset. The dataset is created inside the notebook, so no external file is needed. The amounts are in arbitrary currency units and do not represent real student spending.

## What the Notebook Does
- Creates and explores the dataset with Pandas (`head`, `shape`, `info`, `describe`)
- Checks for missing values and duplicate rows
- Calculates statistics with Pandas and NumPy (total, average, spending by category and by payment method, highest expense)
- Creates a "Total Spending by Category" bar chart with Matplotlib
- Presents findings and a conclusion

## Files
- `Week4_Student_Spending_Analyzer.ipynb`: the main notebook (with outputs and chart)
- `Week4_Student_Spending_Analyzer.pdf`: PDF export of the notebook

## How to Run
1. Open [Google Colab](https://colab.research.google.com).
2. Choose `File > Upload notebook` and upload the `.ipynb` file.
3. Choose `Runtime > Run all`.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Google Colab
